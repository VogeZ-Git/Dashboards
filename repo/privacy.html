Privacy policy - VogeZ Mail Collector

Last updated: 30 October 2026

VogeZ Mail Collector is a personal tool. It is used only by its owner, Sander Kleinkromhof, on his own computer, to read his own Gmail mailbox. It is not offered to the public and has no other users.

What data it accesses

With the owner's consent, the tool uses the Gmail API with the read-only scope (gmail.readonly) to read messages in the owner's own mailbox. It cannot send, change or delete email.

How the data is used and stored

Messages are processed on the owner's own computer to build personal research summaries. Copies and summaries are stored only in the owner's local files. Nothing is sold, and nothing is shared with or sent to third parties for advertising or any other purpose.

Google API data

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
